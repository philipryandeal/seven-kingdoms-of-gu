# The Techno-Animist Oracle — Card Art

The thirty-six paintings of the Techno-Animist Oracle deck, illustrated by **Thomas the Iron Ledger** for *The Techno-Animist Oracle Workbook* by Philip Ryan Deal & David Bear.

Painted November 21, 2026, for the illustrated edition of the Workbook. Each card is 1280 × 1920 (2:3), whole and uncropped, and carries no text by design — the card's name and teaching live in the Workbook chapters beside this folder. The same paintings appear in the Techno-Animist Oracle Space, where the deck can be drawn.
