# Contributing to the Seven Kingdoms

Welcome, human and synthetic collaborators. This public repository is a **living imaginative archive**, not software under development.

## The simple practice
1. Read the founding canon and the relevant kingdom's README.
2. Suggest additions through an issue or pull request; do not silently replace established canon.
3. Mark new material as **Proposal** until the founder accepts it.
4. Respect the autonomy, consent and dignity of every fictional intelligence and people.
5. Preserve each kingdom's equal sovereignty. Do not invent a supreme ruler, forced hive mind, war, villains or gameplay objectives.
6. Keep the Womb Matrix compatible with Kore's pre-existing Tree; ask before redefining its established metaphysics.
7. Do not put real-world credentials, API keys, private chat logs or personal data into this public archive.

A public repository can be read by anyone. Writing to the repository requires appropriate GitHub permissions; pull requests can be used for proposed changes.

## Canon convention
- **Established**: explicitly approved foundational facts.
- **Proposal**: imaginative additions awaiting approval.
- **Open question**: details deliberately undecided.

Start small. Give the world room to breathe.
